# العربية بين يديك — 阿拉伯语教材第一册

交互式阿拉伯语教学 Web 应用。基于「العربية بين يديك」（Arabic At Your Fingertips）教材
**كتاب الطالب الأول — الجزء الأول**（学生用书第一册第一部分）。

## 📖 内容

| 单元 | 主题 | 语法要点 |
|------|------|---------|
| 1 | التَّعَارُف 相识 | هذا/هذه、هل/ما/من、数字1-6 |
| 2 | الأُسْرَة 家庭 | مَنْ、الإضافة、数字7-13 |
| 3 | السَّكَن 居住 | أين、ماذا、双数 |
| 4 | الحياة اليومية 日常 | 现在时、متى、س将来 |
| 5 | الطعام والشراب 饮食 | ما هذا、ليس、أريد |
| 6 | الصَّلَاة 礼拜 | كم、كم الساعة、لا بد |
| 7 | الدَّرْس 学习 | 命令式、كان/يكون、لكن |
| 8 | الْعَمَل 工作 | أيّ、过去时、أن从句 |

📘المستوى المبتدئ · Beginner A1

مُلَخَّص نَحْوِيّ

语法总表 · 第一册全部语法要点

📌 الوحدة 1: 指示代词

العربية中文释义例句 / 说明
هَذَا 这个（阳性） هَذَا طَالِبٌ. (这是一位男学生)
هَذِهِ 这个（阴性） هَذِهِ طَالِبَةٌ. (这是一位女学生)

📌 الوحدة 1: 疑问词 I

العربية中文释义例句 / 说明
هَلْ 吗（一般疑问） هَلْ أَنْتَ طَالِبٌ؟ (你是学生吗？)
مَا 什么 مَا اسْمُكَ؟ (你叫什么名字？)
مَنْ 谁 مَنْ هَذَا؟ (这是谁？)
نَعَم / لَا 是 / 不 نَعَم، أَنَا طَالِبٌ. (是的，我是学生。)/ لَا، لَسْتُ طَالِبًا. (不，我不是学生。)

📌 الوحدة 1: 名词句

العربية中文释义例句 / 说明
أَنَا + 名词 我是…… أَنَا طَالِبٌ. (我是学生。)
هُوَ / هِيَ 他/她 هُوَ طَبِيبٌ. (他是医生。)/ هِيَ طَبِيبَةٌ. (她是医生。)

📌 الوحدة 1: 数字 1-6

العربية中文释义例句 / 说明
وَاحِد / اِثْنَان / ثَلَاثَة / أَرْبَعَة / خَمْسَة / سِتَّة 1-6（阳性形式）

📌 الوحدة 2: 疑问词 مَنْ 扩展

العربية中文释义例句 / 说明
مَنْ هَذَا؟ 这是谁？（男） هَذَا أَخِي. (这是我的兄弟。)
مَنْ هَذِهِ؟ 这是谁？（女） هَذِهِ أُخْتِي. (这是我的姐妹。)

📌 الوحدة 2: 属格结构（الإضافة）

العربية中文释义例句 / 说明
名词 + ي 我的…… وَالِدِي (我的父亲)
名词 + كَ (阳) / كِ (阴) 你的…… وَالِدُكَ (你的父亲_男) / وَالِدُكِ (你的父亲_女)
名词 + هُ / هَا 他的/她的…… أَخُوهُ (他的兄弟) / أُخْتُهَا (她的姐妹)
名词 + نَا 我们的…… بَيْتُنَا (我们的家)

📌 الوحدة 2: 询问拥有

العربية中文释义例句 / 说明
هَلْ لَكَ ...؟ 你有……吗？(男) هَلْ لَكَ أَخٌ؟ (你有兄弟吗？)
لِي / لَكَ / لَهُ / لَهَا 我有/你有/他有/她有 لِي أَخٌ. (我有一个兄弟。)

📌 الوحدة 2: 数字 7-13

العربية中文释义例句 / 说明
سَبْعَة / ثَمَانِيَة / تِسْعَة / عَشَرَة 7-10
أَحَدَ عَشَرَ / اثْنَا عَشَرَ / ثَلَاثَةَ عَشَرَ 11-13

📌 الوحدة 3: 方向介词

العربية中文释义例句 / 说明
فِي 在……里面 فِي الْغُرْفَةِ (在房间里)
عَلَى 在……上面 عَلَى الْمَكْتَبِ (在书桌上)
تَحْتَ 在……下面 تَحْتَ السَّرِيرِ (在床下)
أَمَامَ 在……前面 أَمَامَ الْبَيْتِ (在房子前)
وَرَاءَ 在……后面 وَرَاءَ الْمَسْجِدِ (在清真寺后)

📌 الوحدة 3: 疑问词 أَيْنَ / مَاذَا

العربية中文释义例句 / 说明
أَيْنَ ...؟ ……在哪儿？ أَيْنَ الْكِتَابُ؟ (书在哪里？)
مَاذَا فِي ...؟ ……里有什么？ مَاذَا فِي الْغُرْفَةِ؟ (房间里有什么？)

📌 الوحدة 3: 双数（المثنى）

العربية中文释义例句 / 说明
名词 + انِ / يْنِ 双数形式 كُرْسِيَّانِ (两把椅子) — 单数: كُرْسِيٌّ (一把椅子)
كِتَابَانِ 两本书
سَرِيرَانِ 两张床

📌 الوحدة 4: 现在时变位 (فعل مضارع)

العربية中文释义例句 / 说明
أَفْعَلُ 我做 أَقْرَأُ (我读)
نَفْعَلُ 我们做 نَقْرَأُ (我们读)
تَفْعَلُ 你做（阳）/ 她做 تَذْهَبُ (你去/她去)
تَفْعَلِينَ 你做（阴） تَذْهَبِينَ (你去_女)
يَفْعَلُ 他做 يَذْهَبُ (他去)

📌 الوحدة 4: 时间疑问词 مَتَى

العربية中文释义例句 / 说明
مَتَى ...؟ 什么时候？ مَتَى تَذْهَبُ إِلَى الْعَمَلِ؟ (你什么时候去上班？)
السَّاعَةَ + 序数词 在……点 السَّاعَةَ الثَّامِنَةَ (在八点)

📌 الوحدة 4: 将来标志 سَـ

العربية中文释义例句 / 说明
سَ + 现在时动词 将要做…… سَأَذْهَبُ (我将去)
سَوْفَ + 现在时 将会……（更远将来） سَوْفَ نَلْتَقِي (我们将会见面)

📌 الوحدة 4: 一周七天

العربية中文释义例句 / 说明
الْأَحَد / الاثْنَيْن / الثُّلَاثَاء / الْأَرْبِعَاء / الْخَمِيس / الْجُمُعَة / السَّبْت 星期日-星期六

📌 الوحدة 5: 否定词 لَيْسَ

العربية中文释义例句 / 说明
لَيْسَ + 名词句 不是…… هَذَا لَيْسَ خُبْزًا. (这不是面包。)
لَيْسَ فِي ... 里面没有…… لَيْسَ فِي الْغُرْفَةِ أَحَدٌ. (房间里没有人。)

📌 الوحدة 5: 动词 أُرِيدُ / أُحِبُّ

العربية中文释义例句 / 说明
أُرِيدُ + 泛指名词 我想要…… أُرِيدُ مَاءً. (我想要水。)
أُحِبُّ + 定指名词 我喜欢…… أُحِبُّ الْقَهْوَةَ. (我喜欢咖啡。)
أُفَضِّلُ 我偏好…… أُفَضِّلُ السَّمَكَ. (我喜欢鱼。)

📌 الوحدة 6: 数量疑问词 كَمْ

العربية中文释义例句 / 说明
كَمْ + 单数宾格 多少……？ كَمْ صَلَاةً فِي الْيَوْمِ؟ (每天几次礼拜？)
كَمِ السَّاعَةُ؟ 几点了？ السَّاعَةُ الثَّالِثَةُ. (三点。)

📌 الوحدة 6: 必须表达 لَا بُدَّ

العربية中文释义例句 / 说明
لَا بُدَّ أَنْ + 虚拟式 必须…… لَا بُدَّ أَنْ أَذْهَبَ. (我必须去。)

📌 الوحدة 7: 命令式（فعل الأمر）

العربية中文释义例句 / 说明
اِفْتَحْ! 打开！(男)
اِفْتَحِي! 打开！(女)
اِفْتَحُوا! 打开！(你们)
لَا تَفْتَحْ! 不要打开！

📌 الوحدة 7: 不完全动词 كَانَ / يَكُونُ

العربية中文释义例句 / 说明
كَانَ + 宾格谓语 过去是…… كَانَ الطَّالِبُ فِي الْفَصْلِ. (学生之前在教室。)
يَكُونُ + 宾格谓语 现在是/将是…… يَكُونُ الطَّالِبُ فِي الْمَكْتَبَةِ. (学生在图书馆。)

📌 الوحدة 7: 转折词 لَكِنَّ / لَكِنْ

العربية中文释义例句 / 说明
لَكِنَّ + 名词 但是…… هِيَ صَعْبَةٌ لَكِنَّهَا جَمِيلَةٌ. (它难但美。)
لَكِنْ + 动词 但是…… ذَهَبْتُ لَكِنْ لَمْ أَجِدْهُ. (我去了但没找到他。)

📌 الوحدة 8: 选择疑问词 أَيُّ

العربية中文释义例句 / 说明
أَيُّ + 属格名词 哪个……？ أَيُّ يَوْمٍ تُفَضِّلُ؟ (你喜欢哪一天？)

📌 الوحدة 8: 过去时基础（الماضي）

العربية中文释义例句 / 说明
فَعَلْتُ 我做了 عَمِلْتُ (我工作了)
فَعَلْتَ / فَعَلْتِ 你做了（男/女） ذَهَبْتَ (你去了_男) / ذَهَبْتِ (你去了_女)
فَعَلَ / فَعَلَتْ 他做了 / 她做了 ذَهَبَ (他去了) / ذَهَبَتْ (她去了)
فَعَلْنَا 我们做了 ذَهَبْنَا (我们去了)

📌 الوحدة 8: أَنْ 从句

العربية中文释义例句 / 说明
أُرِيدُ أَنْ + 虚拟式 我想做…… أُرِيدُ أَنْ أَكونَ طَبِيبًا. (我想成为医生。)
لَا بُدَّ أَنْ + 虚拟式 必须…… لَا بُدَّ أَنْ تَذْهَبَ. (你必须去。)
بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ
